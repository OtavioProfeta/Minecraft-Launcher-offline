# Contributing to Minecraft Launcher

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork:
```bash
   git clone https://github.com/your-username/minecraft-launcher.git
   cd minecraft-launcher
```

3. **Create a branch** from `develop`:
```bash
   git checkout develop
   git checkout -b feature/your-feature
```

4. **Commit** with clear messages:
```bash
   git commit -m "feat: add dark mode support"
```

5. **Push** to your fork:
```bash
   git push origin feature/your-feature
```

6. **Open a Pull Request** to the `develop` branch
   - Describe what was changed
   - Attach screenshots if relevant

## Commit Standards

- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `refactor:` code refactoring
- `test:` tests

## Allowed Branches for Contributors

- `feature/*` ← create new features here
- `bugfix/*` ← fix bugs here

❌ DO NOT create PRs directly to `main`
